Тексты по информационным технологиям

  • Хостинг - подготовленное место для размещения/публикации сайта в интернете.
  • Цикл разработки сайта - полезно иметь об этом представление.
  • HTML - основной язык веб-страниц. Оформление текста и других объектов и данных в теги с указанием атрибутов и их значений если нужно. Основных тегов несколько десятков и их можно довольно быстро освоить. HTML без скриптов это даже не язык программирования со сложной логикой и функциями , а просто описательный компьютерный язык. А вот скрипты JavaScript внедрённые в HTML-страницы или подключаемые к ним это уже серьёзное программирование, когда веб-страница не просто отображается в веб-браузере, а работает как интерактивная программа интерпретируемая веб-браузером.
  • CSS - стилевое оформление материалов веб-страниц.
  • SVG - векторные изображения, которые можно прямо кодировать в командах и кодах как в когда-то рисовали на экране в Бейсике или Си в графическом режиме. А можно найти векторные редакторы и просто рисовать сохраняя в формат SVG. В HTML5 появился тег svg и код можно прямо в него вставить, или разместить отдельный svg-файл как файл изображения через тег img с указанием ссылки.
  • PHP - язык программирования для исполнения на сервере для подготовки веб-страниц. Иногда достаточно минимальное использование PHP: для вставки общих частей различных веб-страниц, для простых логических условий и простых информационных вставок, и этому можно быстро научиться. Но на крупных сайтах обычно используется объектно-ориентированное программирование с использованием различных структур данных, различные библиотеки классов и функций - все эти возможности есть в PHP и тогда также необходимо уделить внимание безопасности.
  • Работа с лёгкой базой данных SQLite из PHP. База данных удобна при наличии интерактивной обратной связи с посетителями: если есть гостевая книга, возможность писать комментарии, возможность поиска по сайту, регистрация пользователей.
  • GIT - это система контроля версий. Она полезна при значительных объёмах работ по изменению кода и при работе в команде. В принципе при разработке простого HTML/CSS сайта на несколько страниц без JavaScript, без серверных скриптов GIT обычно не требуется. А вот если пишется несколько взаимосвязанных скриптов на PHP и/или JavaScript или других языках программирования, то наверное стоит освоить GIT.
