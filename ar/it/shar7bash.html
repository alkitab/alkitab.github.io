شَرْحٌ مُفَصَّلٌ لِأَوَامِرِ وَهَيَاكِلِ بَاشْ (Bash)

الْمُقَدِّمَةُ: تُعَدُّ بَاشْ (Bash) وَهِيَ اخْتِصَارٌ لِجُمْلَةِ Bourne Again Shell، أَحَدَ أَشْهَرِ الصَّدَفَاتِ (Shells) فِي أَنْظِمَةِ لِينُكْس وَيُونِكْس. وَتُسْتَخْدَمُ لِتَنْفِيذِ الْأَوَامِرِ، وَإِدَارَةِ الْمِلَفَّاتِ، وَكِتَابَةِ النَّصَائِحِ الْبَرْمَجِيَّةِ (Scripts). وَتَدْعَمُ بَاشْ الْمُتَغَيِّرَاتِ، وَالْمَصْفُوفَاتِ، وَالشُّرُوطَ، وَالْحَلَقَاتِ، وَالدَّوَالَّ، وَالْعَمَلِيَّاتِ الرِّيَاضِيَّةَ، مِمَّا يَجْعَلُهَا أَدَاةً قَوِيَّةً لِلْأَتْمَتَةِ وَإِدَارَةِ النِّظَامِ. وَفِي هَذَا الشَّرْحِ نُقَدِّمُ تَعْرِيفًا مُفَصَّلًا لِأَهَمِّ الْأَوَامِرِ وَالْهَيَاكِلِ مَعَ أَمْثِلَةٍ عَمَلِيَّةٍ مُفِيدَةٍ.

أَوَّلًا: الْأَوَامِرُ الْأَسَاسِيَّةُ لِلْعَرْضِ وَالِاسْتِعْلَامِ

(1) أَمْرُ ls

التَّعْرِيفُ: هُوَ أَمْرٌ يُسْتَخْدَمُ لِعَرْضِ قَائِمَةِ الْمِلَفَّاتِ وَالدَّلَائِلِ (Directories) الْمَوْجُودَةِ فِي الدَّلِيلِ الْحَالِيِّ أَوْ فِي الْمَسَارِ الْمُحَدَّدِ.

الْوَظِيفَةُ: يُمَكِّنُ الْمُسْتَخْدِمَ مِنْ مُعَايَنَةِ مُحْتَوَيَاتِ أَيِّ دَلِيلٍ بِسُهُولَةٍ، مَعَ خِيَارَاتٍ لِعَرْضِ التَّفَاصِيلِ كَالْأَذْوَاتِ وَالْأَحْجَامِ وَتَوَارِيخِ التَّعْدِيلِ.

مِثَالٌ:

ls ls -l # عَرْضٌ مُفَصَّلٌ ls -a # عَرْضُ الْمِلَفَّاتِ الْمَخْفِيَّةِ ls -lh /home # حَجْمٌ بِصِيغَةٍ قِرَائِيَّةٍ ls -lt # تَرْتِيبٌ بِالتَّارِيخِ

مُلَاحَظَاتٌ: الْخَيَارُ -l يُعْطِي عَرْضًا طَوِيلًا بِالتَّفَاصِيل، وَ-a يُظْهِرُ الْمِلَفَّاتِ الْمَخْفِيَّةَ الَّتِي تَبْدَأُ بِنُقْطَةٍ، وَ-h يُظْهِرُ الْأَحْجَامَ بِصِيغَةٍ يَسِيرَةٍ كَـ(K, M, G).

(2) أَمْرُ cal

التَّعْرِيفُ: هُوَ أَمْرٌ يَعْرِضُ تَقْوِيمًا شَهْرِيًّا أَوْ سَنَوِيًّا لِلشَّهْرِ وَالسَّنَةِ الْحَالِيَّيْنِ أَوْ لِأَيِّ شَهْرٍ وَسَنَةٍ مُحَدَّدَيْنِ.

الْوَظِيفَةُ: يُسْتَخْدَمُ لِمَعْرِفَةِ أَيَّامِ الْأُسْبُوعِ وَتَوَارِيخِ الشُّهُورِ بِدُونِ الْحَاجَةِ إِلَى تَطْبِيقَاتٍ خَارِجِيَّةٍ، وَهُوَ مُفِيدٌ جِدًّا فِي التَّخْطِيطِ وَالْمُنَظَّمَةِ.

مِثَالٌ:

cal # تَقْوِيمُ الشَّهْرِ الْحَالِيَةِ cal 2024 # تَقْوِيمُ سَنَةٍ كَامِلَةٍ cal 3 2024 # تَقْوِيمُ مَارِسَ 2024 cal -y # تَقْوِيمٌ سَنَوِيٌّ لِلسَّنَةِ الْحَالِيَةِ

مُلَاحَظَاتٌ: يُمْكِنُ تَحْدِيدُ الشَّهْرِ وَالسَّنَةِ مَعًا بِتَمَرِيرِ رَقَمِ الشَّهْرِ ثُمَّ السَّنَةِ، كَمَا فِي cal 3 2024 لِعَرْضِ شَهْرِ مَارِسَ لِسَنَةِ 2024.

(3) أَمْرُ date

التَّعْرِيفُ: هُوَ أَمْرٌ يُظْهِرُ التَّارِيخَ وَالْوَقْتَ الْحَالِيَّيْنِ لِلنِّظَامِ، وَيُمْكِنُ تَنْسِيقُهُمَا بِأَشْكَالٍ مُخْتَلِفَةٍ.

الْوَظِيفَةُ: يُسْتَخْدَمُ لِمَعْرِفَةِ التَّارِيخِ وَالْوَقْتِ، وَلِتَنْسِيقِهِمَا فِي النَّصَائِحِ الْبَرْمَجِيَّةِ، وَلِضَبْطِ تَوَارِيخِ الْمِلَفَّاتِ، وَلِإِنْشَاءِ أَسْمَاءِ مِلَفَّاتٍ تَحْوِي طَابِعًا زَمَنِيًّا.

مِثَالٌ:

date # التَّارِيخُ وَالْوَقْتُ الْحَالِيَّانِ date +"%Y-%m-%d" # الصِّيغَةُ: سَنَة-شَهْر-يَوْم date +"%H:%M:%S" # الصِّيغَةُ: سَاعَة:دَقِيقَة:ثَانِيَة date +"%d/%m/%Y %H:%M" # صِيغَةٌ كَامِلَةٌ date -u # التَّارِيخُ بِتَوْقِيتِ غْرِينْتْش

مُلَاحَظَاتٌ: يُسْتَخْدَمُ الرَّمْزُ + مَعَ سَلْسِلَةِ التَّنْسِيقِ لِتَحْدِيدِ الشَّكْلِ الْمُرَادِ، كَمَا يُسْتَخْدَمُ %Y لِلسَّنَةِ، وَ%m لِلشَّهْرِ، وَ%d لِلْيَوْمِ، وَ%H لِلسَّاعَةِ، وَ%M لِلدَّقِيقَةِ، وَ%S لِلثَّانِيَةِ.

(4) أَمْرُ cat

التَّعْرِيفُ: هُوَ أَمْرٌ يَقْرَأُ مُحْتَوَى مِلَفٍّ وَيَعْرِضُهُ عَلَى الشَّاشَةِ، وَيُمْكِنُهُ دَمْجُ مِلَفَّاتٍ مُتَعَدِّدَةٍ مَعًا (Concatenate).

الْوَظِيفَةُ: يُسْتَخْدَمُ لِعَرْضِ مُحْتَوَى الْمِلَفَّاتِ النَّصِّيَّةِ بِسُرْعَةٍ، وَلِدَمْجِ مِلَفَّاتٍ مُتَعَدِّدَةٍ فِي مِلَفٍّ وَاحِدٍ، وَلِإِنْشَاءِ مِلَفَّاتٍ جَدِيدَةٍ مِنْ مُدْخَلَاتِ الْمُسْتَخْدِمِ.

مِثَالٌ:

cat file.txt # عَرْضُ مُحْتَوَى الْمِلَفِّ cat file1.txt file2.txt # دَمْجُ مِلَفَّيْنِ وَعَرْضُهُمَا cat > new.txt # إِنْشَاءُ مِلَفٍّ جَدِيدٍ cat -n file.txt # عَرْضٌ مَعَ أَرْقَامِ السُّطُورِ

مُلَاحَظَاتٌ: الْخَيَارُ -n يُظْهِرُ أَرْقَامَ السُّطُورِ، وَ-b يُظْهِرُهَا لِلْسُطُورِ غَيْرِ الْفَارِغَةِ فَقَطْ. وَيُسْتَخْدَمُ cat > file لِإِنْشَاءِ مِلَفٍّ جَدِيدٍ مِنْ مُدْخَلَاتِ النَّصِّ.

(5) أَمْرُ history

التَّعْرِيفُ: هُوَ أَمْرٌ يُظْهِرُ قَائِمَةً بِالْأَوَامِرِ الَّتِي نَفَّذَهَا الْمُسْتَخْدِمُ سَابِقًا فِي الطَّرَفِيَّةِ (Terminal).

الْوَظِيفَةُ: يُسَاعِدُ عَلَى تَذَكُّرِ الْأَوَامِرِ الْمُنْفَّذَةِ، وَإِعَادَةِ اسْتِخْدَامِهَا دُونَ إِعَادَةِ كِتَابَتِهَا، وَمُرَاجَعَةِ النَّشَاطِ الْبَرْمَجِيِّ لِأَغْرَاضِ التَّحَقُّقِ وَالتَّدْقِيقِ.

مِثَالٌ:

history # عَرْضُ الْأَوَامِرِ السَّابِقَةِ history 10 # آخَرُ عَشَرَةِ أَوَامِرَ !42 # تَنْفِيذُ الأَمْرِ رَقْمُ 42 !! # تَكْرَارُ الأَمْرِ الْأَخِيرِ !ls # آخَرُ أَمْرٍ يَبْدَأُ بـ ls

مُلَاحَظَاتٌ: تُحْفَظُ الْأَوَامِرُ فِي مِلَفِ ~/.bash_history، وَيُمْكِنُ اسْتِدْعَاءُ أَيِّ أَمْرٍ بِرَقَمِهِ بِوَاسِطَةِ عَلَامَةِ التَّعَجُّبِ !، كَمَا يُسْتَخْدَمُ !! لِتَكْرَارِ الْأَمْرِ الْأَخِيرِ.

(6) أَمْرُ echo

التَّعْرِيفُ: هُوَ أَمْرٌ يَطْبَعُ النَّصَّ الْمُمَرَّرَ إِلَيْهِ عَلَى الشَّاشَةِ (Standard Output).

الْوَظِيفَةُ: يُسْتَخْدَمُ لِعَرْضِ الرَّسَائِلِ، وَقِيمَةِ الْمُتَغَيِّرَاتِ، وَإِنْشَاءِ مِلَفَّاتٍ نَصِّيَّةٍ بِسُرْعَةٍ، وَإِظْهَارِ مَخْرَجَاتِ النَّصَائِحِ الْبَرْمَجِيَّةِ لِلْمُسْتَخْدِمِ.

مِثَالٌ:

echo "مَرْحَبًا بِالْعَالَمِ" # طَبَاعَةُ نَصٍّ echo $HOME # قِيمَةُ مُتَغَيِّرٍ echo -n "بِدُونِ سَطْرٍ جَدِيدٍ" # بِدُونِ \n echo -e "سَطْر1\nسَطْر2" # تَفْسِيرُ الرُّمُوزِ echo "نَصٌّ" > file.txt # كِتَابَةٌ فِي مِلَفٍّ

مُلَاحَظَاتٌ: الْخَيَارُ -n يَمْنَعُ إِضَافَةَ سَطْرٍ جَدِيدٍ فِي النِّهَايَةِ، وَ-e يُفَعِّلُ تَفْسِيرَ الرُّمُوزِ الْخَاصَّةِ كَـ\n لِلسَّطْرِ الْجَدِيدِ وَ\t لِلْجَدْوَلَةِ.

(7) أَمْرُ printf

التَّعْرِيفُ: هُوَ أَمْرٌ يُطْبَعُ النَّصَّ مَعَ التَّحَكُّمِ فِي التَّنْسِيقِ بِنَفْسِ طَرِيقَةِ دَالَّةِ printf فِي لُغَةِ C.

الْوَظِيفَةُ: يُسْتَخْدَمُ حِينَمَا يَكُونُ التَّحَكُّمُ الدَّقِيقُ فِي تَنْسِيقِ الْمُخْرَجِ مَطْلُوبًا، كَتَحْدِيدِ عَدَدِ الْخَانَاتِ، أَوْ تَنْسِيقِ الْأَرْقَامِ، أَوْ مُحَاذَاةِ النُّصُوصِ.

مِثَالٌ:

printf "الِاسْمُ: %s\n" "أَحْمَدُ" printf "الْعُمْرُ: %d\n" 25 printf "السَّعْرُ: %.2f\n" 19.99 printf "%-10s | %5d\n" "اسْمٌ" 42 printf "مُحَاذَاةٌ: %5d\n" 7

مُلَاحَظَاتٌ: الرَّمْزُ %s لِلنُّصُوصِ، وَ%d لِلْأَعْدَادِ الصَّحِيحَةِ، وَ%f لِلْأَعْدَادِ الْعَشْرِيَّةِ. وَيُسْتَخْدَمُ %-10s لِمُحَاذَاةٍ لِلْيَسَارِ بِعَرْضِ 10 خَانَاتٍ، وَ%5d لِمُحَاذَاةٍ لِلْيَمِينِ بِعَرْضِ 5 خَانَاتٍ.

ثَانِيًا: أَوَامِرُ إِدَارَةِ الْمِلَفَّاتِ وَالدَّلَائِلِ

(8) أَمْرُ mkdir

التَّعْرِيفُ: هُوَ أَمْرٌ يُسْتَخْدَمُ لِإِنْشَاءِ دَلِيلٍ (Directory) جَدِيدٍ أَوْ مَجْمُوعَةٍ مِنَ الدَّلَائِلِ فِي آنٍ وَاحِدٍ.

الْوَظِيفَةُ: يُمَكِّنُ الْمُسْتَخْدِمَ مِنْ تَنْظِيمِ مِلَفَّاتِهِ فِي بِنْيَةٍ شَجَرِيَّةٍ، مَعَ خِيَارِ إِنْشَاءِ الدَّلَائِلِ الْمُتَدَاخِلَةِ (Nested) دَفْعَةً وَاحِدَةً.

مِثَالٌ:

mkdir myfolder # إِنْشَاءُ دَلِيلٍ mkdir dir1 dir2 dir3 # إِنْشَاءُ ثَلَاثَةٍ دَلَائِلَ mkdir -p a/b/c # إِنْشَاءٌ مُتَدَاخِلٌ mkdir -m 755 newdir # إِنْشَاءٌ مَعَ إِذْنٍ

مُلَاحَظَاتٌ: الْخَيَارُ -p يُنشِئُ الدَّلَائِلَ الْأَبَوِيَّةَ إِنْ لَمْ تَكُنْ مَوْجُودَةً، وَلَا يُظْهِرُ خَطَأً إِذَا كَانَ الدَّلِيلُ مَوْجُودًا. وَ-m يُحَدِّدُ التَّصْرِيحَ (Permission).

(9) أَمْرُ cd

التَّعْرِيفُ: هُوَ أَمْرٌ يُغَيِّرُ الدَّلِيلَ الْحَالِيَّ (Current Directory) الَّذِي يَعْمَلُ فِيهِ الْمُسْتَخْدِمُ.

الْوَظِيفَةُ: يُسْتَخْدَمُ لِلِانْتِقَالِ بَيْنَ الدَّلَائِلِ بِسُهُولَةٍ، فَيُمْكِنُ الذَّهَابُ إِلَى دَلِيلٍ مُعَيَّنٍ، أَوْ إِلَى الدَّلِيلِ الْأَبِ، أَوْ إِلَى الدَّلِيلِ الْمَنْزِلِيِّ.

مِثَالٌ:

cd /home/user # الذَّهَابُ إِلَى مَسَارٍ مُحَدَّدٍ cd .. # الصُّعُودُ إِلَى الدَّلِيلِ الْأَبِ cd ~ # الذَّهَابُ إِلَى الْمَنْزِلِ cd - # الْعَوْدَةُ لِلدَّلِيلِ السَّابِقِ cd # الذَّهَابُ إِلَى الْمَنْزِلِ

مُلَاحَظَاتٌ: الرَّمْزُ ~ يُمَثِّلُ الدَّلِيلَ الْمَنْزِلِيَّ، وَ.. يُشِيرُ إِلَى الدَّلِيلِ الْأَبِ، وَ- يُرْجِعُ إِلَى الدَّلِيلِ السَّابِقِ قَبْلَ التَّغْيِيرِ الْأَخِيرِ.

(10) أَمْرُ chmod

التَّعْرِيفُ: هُوَ أَمْرٌ يُغَيِّرُ تَصْرِيحَاتِ (Permissions) الْمِلَفَّاتِ وَالدَّلَائِلِ، أَيْ مَنْ يَقْدِرُ عَلَى قِرَاءَتِهَا أَوْ كِتَابَتِهَا أَوْ تَنْفِيذِهَا.

الْوَظِيفَةُ: يُسْتَخْدَمُ لِضَبْطِ مُسْتَوَى الْحَمَايَةِ لِلْمِلَفَّاتِ، فَيُمْكِنُ مَنْعُ الْآخَرِينَ مِنَ الْقِرَاءَةِ أَوِ التَّعْدِيلِ، أَوْ السَّمْحُ لَهُمْ بِالتَّنْفِيذِ.

مِثَالٌ:

chmod 755 script.sh # rwxr-xr-x chmod 644 file.txt # rw-r--r-- chmod +x script.sh # إِضَافَةُ تَصْرِيحِ التَّنْفِيذِ chmod u+w file.txt # لِلْمَالِكِ كِتَابَةٌ chmod -R 755 myfolder # تَطْبِيقٌ تَكْرَارِيٌّ

مُلَاحَظَاتٌ: الْأَرْقَامُ تَدُلُّ عَلَى التَّصْرِيحَاتِ: 7 = rwx، 5 = r-x، 4 = r--. الْخَيَارُ -R يُطَبِّقُ التَّغْيِيرَ عَلَى جَمِيعِ الْمِلَفَّاتِ دَاخِلَ الدَّلِيلِ بِالتَّكْرَارِ.

(11) أَمْرُ mv

التَّعْرِيفُ: هُوَ أَمْرٌ يُسْتَخْدَمُ لِنَقْلِ (Move) الْمِلَفَّاتِ وَالدَّلَائِلِ مِنْ مَكَانٍ إِلَى آخَرَ، أَوْ لِإِعَادَةِ تَسْمِيَتِهَا (Rename).

الْوَظِيفَةُ: يُمَكِّنُ الْمُسْتَخْدِمَ مِنْ تَنْظِيمِ مِلَفَّاتِهِ بِنَقْلِهَا بَيْنَ الدَّلَائِلِ، أَوْ تَغْيِيرِ أَسْمَائِهَا دُونَ نَسْخِهَا، مِمَّا يُوفِّرُ الْوَقْتَ وَالْمِسَاحَةَ.

مِثَالٌ:

mv file.txt /tmp/ # نَقْلٌ إِلَى دَلِيلٍ آخَرَ mv old.txt new.txt # إِعَادَةُ تَسْمِيَةٍ mv -i file.txt /tmp/ # اسْتِئْذَانٌ قَبْلَ الِاسْتِبْدَالِ mv -u file.txt /tmp/ # نَقْلٌ إِذَا كَانَ أَحْدَثَ mv *.txt /backup/ # نَقْلُ جَمِيعِ النُّصُوصِ

مُلَاحَظَاتٌ: الْخَيَارُ -i يَطْلُبُ التَّأْكِيدَ قَبْلَ الِاسْتِبْدَالِ، وَ-u يَنْقُلُ فَقَطْ إِذَا كَانَ الْمِلَفُ الْمَصْدَرِيُّ أَحْدَثَ مِنَ الْهَدَفِ أَوْ لَمْ يَكُنْ مَوْجُودًا.

(12) أَمْرُ cp

التَّعْرِيفُ: هُوَ أَمْرٌ يَسْتَخْدِمُ لِنَسْخِ (Copy) الْمِلَفَّاتِ وَالدَّلَائِلِ مَعَ الْإِبْقَاءِ عَلَى الْأَصْلِ.

الْوَظِيفَةُ: يُسْتَخْدَمُ لِإِنْشَاءِ نُسْخَةٍ احْتِيَاطِيَّةٍ مِنَ الْمِلَفَّاتِ، أَوْ لِنَسْخِ مِلَفٍّ إِلَى مَوْضِعٍ آخَرَ، أَوْ لِنَسْخِ دَلِيلٍ كَامِلٍ بِمُحْتَوَيَاتِهِ.

مِثَالٌ:

cp file.txt backup.txt # نَسْخُ مِلَفٍّ cp file.txt /tmp/ # نَسْخٌ إِلَى دَلِيلٍ cp -r myfolder /backup/ # نَسْخُ دَلِيلٍ بِالتَّكْرَارِ cp -i file.txt /tmp/ # اسْتِئْذَانٌ قَبْلَ الِاسْتِبْدَالِ cp *.txt /backup/ # نَسْخُ جَمِيعِ النُّصُوصِ

مُلَاحَظَاتٌ: الْخَيَارُ -r (أَوْ -R) ضَرُورِيٌّ لِنَسْخِ الدَّلَائِلِ بِمُحْتَوَيَاتِهَا، وَ-i يَطْلُبُ التَّأْكِيدَ قَبْلَ الِاسْتِبْدَالِ، وَ-p يُحَافِظُ عَلَى التَّصْرِيحَاتِ وَالتَّوَارِيخِ.

(13) أَمْرُ rm

التَّعْرِيفُ: هُوَ أَمْرٌ يَحْذِفُ (Remove) الْمِلَفَّاتِ وَالدَّلَائِلَ، وَلَا يُمْكِنُ الِاسْتِرْجَاعُ بَعْدَ الْحَذْفِ غَالِبًا.

الْوَظِيفَةُ: يُسْتَخْدَمُ لِحَذْفِ الْمِلَفَّاتِ غَيْرِ الضَّرُورِيَّةِ لِتَحْرِيرِ الْمِسَاحَةِ، أَوْ لِحَذْفِ الدَّلَائِلِ بِمُحْتَوَيَاتِهَا.

مِثَالٌ:

rm file.txt # حَذْفُ مِلَفٍّ rm -i file.txt # حَذْفٌ مَعَ التَّأْكِيدِ rm -r myfolder # حَذْفُ دَلِيلٍ بِالتَّكْرَارِ rm -f file.txt # حَذْفٌ إِجْبَارِيٌّ rm *.log # حَذْفُ جَمِيعِ مِلَفَّاتِ الْمُحْتَوَيَاتِ

مُلَاحَظَاتٌ: احْذَرْ مِنْ أَمْرِ rm -rf لِأَنَّهُ يَحْذِفُ بِقُوَّةٍ وَبِدُونِ تَأْكِيدٍ. الْخَيَارُ -r لِلدَّلَائِلِ، وَ-f لِلْحَذْفِ الْإِجْبَارِيِّ، وَ-i لِلطَّلَبِ التَّأْكِيدَ قَبْلَ كُلِّ حَذْفٍ.

(14) أَمْرُ rmdir

التَّعْرِيفُ: هُوَ أَمْرٌ يَحْذِفُ دَلِيلًا فَارِغًا (Remove Directory) فَقَطْ، وَلَا يَحْذِفُ مَا فِيهِ مِنْ مِلَفَّاتٍ.

الْوَظِيفَةُ: يُسْتَخْدَمُ لِتَنْظِيفِ الدَّلَائِلِ الْفَارِغَةِ بِأَمَانٍ، دُونَ خَطَرِ حَذْفِ مِلَفَّاتٍ مُهِمَّةٍ بِالْخَطَأِ.

مِثَالٌ:

rmdir emptyfolder # حَذْفُ دَلِيلٍ فَارِغٍ rmdir dir1 dir2 # حَذْفُ أَكْثَرَ مِنْ وَاحِدٍ rmdir -p a/b/c # حَذْفٌ مُتَسَلْسِلٌ لِلْأَبَوِيِّينَ

مُلَاحَظَاتٌ: لَا يَعْمَلُ إِلَّا إِذَا كَانَ الدَّلِيلُ فَارِغًا تَمَامًا. الْخَيَارُ -p يَحْذِفُ الدَّلِيلَ ثُمَّ أَبَوِيَّهُ إِذَا كَانَا فَارِغَيْنِ أَيْضًا.

(15) أَمْرُ touch

التَّعْرِيفُ: هُوَ أَمْرٌ يُسْتَخْدَمُ لِإِنْشَاءِ مِلَفٍّ فَارِغٍ، أَوْ لِتَحْدِيثِ تَوَارِيخِ الْوُصُولِ وَالتَّعْدِيلِ لِمِلَفٍّ مَوْجُودٍ.

الْوَظِيفَةُ: يُسْتَخْدَمُ لِإِنْشَاءِ مِلَفَّاتٍ فَارِغَةٍ بِسُرْعَةٍ، أَوْ لِتَحْدِيثِ الطَّابِعِ الزَّمَنِيِّ لِمِلَفٍّ دُونَ تَعْدِيلِ مُحْتَوَاهُ.

مِثَالٌ:

touch newfile.txt # إِنْشَاءُ مِلَفٍّ فَارِغٍ touch f1.txt f2.txt f3.txt # إِنْشَاءُ ثَلَاثَةِ مِلَفَّاتٍ touch -t 202401011200 file # ضَبْطُ تَارِيخٍ مُعَيَّنٍ touch -a file.txt # تَحْدِيثُ وَقْتِ الْوُصُولِ فَقَطْ

مُلَاحَظَاتٌ: إِذَا كَانَ الْمِلَفُ مَوْجُودًا، يُحَدِّثُ touch وَقْتَ آخِرِ تَعْدِيلٍ دُونَ تَغْيِيرِ الْمُحْتَوَى. الْخَيَارُ -t يُحَدِّدُ تَارِيخًا بِصِيغَةِ [[CC]YY]MMDDhhmm[.ss].

ثَالِثًا: أَوَامِرُ الشَّبَكَةِ

(16) أَمْرُ wget

التَّعْرِيفُ: هُوَ أَمْرٌ غَيْرُ تَفَاعُلِيٍّ لِتَنْزِيلِ (Download) الْمِلَفَّاتِ مِنَ الْإِنْتِرْنِتِ عَبْرَ بَرُوتُوكُولَاتِ HTTP وHTTPS وFTP.

الْوَظِيفَةُ: يُسْتَخْدَمُ لِتَنْزِيلِ الْمِلَفَّاتِ تِلْقَائِيًّا، حَتَّى مَعَ انْقِطَاعِ الشَّبَكَةِ، لِأَنَّهُ يُكْمِلُ التَّنْزِيلَ مِنْ حَيْثُ تَوَقَّفَ.

مِثَالٌ:

wget https://example.com/file.zip wget -c https://example.com/large.iso # مُتَابَعَةُ التَّنْزِيلِ wget -O output.zip https://example.com/file.zip wget -m https://example.com/ # نَسْخُ مَوْقِعٍ كَامِلٍ wget -q https://example.com/file.zip # هَادِئٌ بِدُونِ مُخْرَجَاتٍ

مُلَاحَظَاتٌ: الْخَيَارُ -c لِمُتَابَعَةِ التَّنْزِيلِ الْمُقْطَعِ، وَ-O لِحِفْظِ الْمِلَفِّ بِاسْمٍ مُخْتَلِفٍ، وَ-m لِنَسْخِ مَوْقِعٍ كَامِلٍ، وَ-q لِلْوَضْعِ الْهَادِئِ.

(17) أَمْرُ curl

التَّعْرِيفُ: هُوَ أَمْرٌ لِنَقْلِ الْبَيَانَاتِ مِنْ أَوْ إِلَى خَادِمٍ، وَيَدْعَمُ بَرُوتُوكُولَاتٍ مُتَعَدِّدَةً كَـHTTP وHTTPS وFTP وSCP.

الْوَظِيفَةُ: يُسْتَخْدَمُ لِاسْتِرْجَاعِ مُحْتَوَى الصَّفَحَاتِ، وَاخْتِبَارِ وَاجِهَاتِ الْبَرْمَجَةِ (APIs)، وَإِرْسَالِ الطَّلَبَاتِ بِأَنْوَاعٍ مُخْتَلِفَةٍ (GET, POST, PUT, DELETE).

مِثَالٌ:

curl https://example.com curl -O https://example.com/file.zip # حِفْظٌ بِنَفْسِ الِاسْمِ curl -X POST -d "name=ahmed" https://api.example.com curl -H 'Authorization: Bearer TOKEN' https://api.example.com curl -s https://example.com # هَادِئٌ

مُلَاحَظَاتٌ: الْخَيَارُ -O يَحْفَظُ الْمِلَفَّ بِاسْمِهِ الْأَصْلِيِّ، وَ-X يُحَدِّدُ نَوْعَ الطَّلَبِ، وَ-d لِإِرْسَالِ بَيَانَاتٍ، وَ-H لِإِضَافَةِ تَرْأِيسَاتٍ (Headers)، وَ-s لِلْوَضْعِ الْهَادِئِ.

رَابِعًا: عَوَامِلُ إِعَادَةِ التَّوْجِيهِ

(18) الْعَامِلُ > (إِعَادَةُ تَوْجِيهٍ)

التَّعْرِيفُ: هُوَ عَامِلٌ يُعِيدُ تَوْجِيهَ (Redirect) الْمُخْرَجَاتِ الْقِيَاسِيَّةَ (Standard Output) لِلْأَمْرِ إِلَى مِلَفٍّ، مَعَ الِاسْتِبْدَالِ الْكَامِلِ لِمُحْتَوَاهُ.

الْوَظِيفَةُ: يُسْتَخْدَمُ لِحِفْظِ مُخْرَجَاتِ الْأَمْرِ فِي مِلَفٍّ، بَدَلًا مِنْ عَرْضِهَا عَلَى الشَّاشَةِ. وَإِذَا كَانَ الْمِلَفُّ مَوْجُودًا، يُسْتَبْدَلُ مُحْتَوَاهُ كَامِلًا.

مِثَالٌ:

echo "أَهْلًا" > file.txt # كِتَابَةٌ فِي مِلَفٍّ ls -l > listing.txt # حِفْظُ قَائِمَةٍ date > timestamp.txt # حِفْظُ التَّارِيخِ whoami > user.txt # حِفْظُ اسْمِ الْمُسْتَخْدِمِ

مُلَاحَظَاتٌ: احْذَرْ! إِذَا كَانَ الْمِلَفُّ مَوْجُودًا، يَتِمُّ حَذْفُ مُحْتَوَاهُ الْقَدِيمِ وَاسْتِبْدَالُهُ بِالْجَدِيدِ. لِلْإِضَافَةِ بَدَلَ الِاسْتِبْدَالِ، اسْتَخْدِمْ >>.

(19) الْعَامِلُ >> (إِضَافَةٌ إِلَى مِلَفٍّ)

التَّعْرِيفُ: هُوَ عَامِلٌ يُعِيدُ تَوْجِيهَ الْمُخْرَجَاتِ إِلَى مِلَفٍّ، وَلَكِنْ بِالْإِضَافَةِ (Append) إِلَى مُحْتَوَاهُ الْمَوْجُودِ دُونَ حَذْفِهِ.

الْوَظِيفَةُ: يُسْتَخْدَمُ لِجَمْعِ مُخْرَجَاتِ أَوَامِرٍ مُتَعَدِّدَةٍ فِي مِلَفٍّ وَاحِدٍ، أَوْ لِإِضَافَةِ سُطُورٍ جَدِيدَةٍ إِلَى سِجِلٍّ (Log) قَائِمٍ.

مِثَالٌ:

echo "السَّطْرُ الْأَوَّلُ" > log.txt echo "السَّطْرُ الثَّانِي" >> log.txt # إِضَافَةٌ date >> log.txt # إِضَافَةُ التَّارِيخِ echo "نِهَايَةُ الْعَمَلِ" >> log.txt

مُلَاحَظَاتٌ: الْفَرْقُ الْأَسَاسِيُّ بَيْنَ > وَ>> هُوَ أَنَّ الْأَوَّلَ يَسْتَبْدِلُ مُحْتَوَى الْمِلَفِّ، وَالثَّانِيَ يُضِيفُ إِلَيْهِ. فَاحْرَصْ عَلَى اخْتِيَارِ الْأَنْسَبِ لِعَمَلِكَ.

خَامِسًا: الْمُتَغَيِّرَاتُ

(20) الْمُتَغَيِّرَاتُ فِي بَاشْ

التَّعْرِيفُ: الْمُتَغَيِّرُ (Variable) هُوَ اسْمٌ يُخَزِّنُ قِيمَةً يُمْكِنُ الِاسْتِنَادُ إِلَيْهَا وَتَعْدِيلُهَا خِلَالَ تَنْفِيذِ النَّصِيحَةِ، وَلَا يُحْتَاجُ إِلَى تَصْرِيحِ نَوْعٍ.

الْوَظِيفَةُ: تُسْتَخْدَمُ الْمُتَغَيِّرَاتُ لِحِفْظِ الْبَيَانَاتِ كَالْأَسْمَاءِ وَالْأَرْقَامِ وَالْمَسَارَاتِ، وَلِتَجَنُّبِ تَكْرَارِ الْقِيَمِ، وَتَسْهِيلِ تَعْدِيلِ النَّصِيحَةِ.

مِثَالٌ:

name="أَحْمَدُ" age=25 echo "$name عُمْرُهُ $age" greeting="مَرْحَبًا بِكَ يَا $name" today=$(date +%Y-%m-%d) echo "الْيَوْمُ: $today" count=10 count=$((count + 5)) # جَمْعٌ readonly PI=3.14 # ثَابِتٌ unset name # حَذْفُ الْمُتَغَيِّرِ

مُلَاحَظَاتٌ: عِنْدَ الْإِسْنَادِ لَا مَسَافَةَ قَبْلَ = أَوْ بَعْدَهَا. لِلْوُصُولِ إِلَى الْقِيمَةِ نَسْتَخْدِمُ الرَّمْزَ $. الْأَمْرُ readonly يَجْعَلُ الْمُتَغَيِّرَ ثَابِتًا، وَunset يَحْذِفُهُ. وَيُمْكِنُ اسْتَخْدَامُ $() لِإِسْنَادِ مُخْرَجِ أَمْرٍ.

سَادِسًا: الْمَصْفُوفَاتُ

(21) الْمَصْفُوفَاتُ (Arrays) فِي بَاشْ

التَّعْرِيفُ: الْمَصْفُوفَةُ هِيَ مَجْمُوعَةٌ مُنَظَّمَةٌ مِنَ الْقِيَمِ تُحْفَظُ تَحْتَ اسْمٍ وَاحِدٍ، وَيُتَحَقَّقُ الْوُصُولُ إِلَى كُلِّ عُنْصَرٍ بِرَقْمِهِ (Index).

الْوَظِيفَةُ: تُسْتَخْدَمُ لِتَخْزِينِ قَائِمَةٍ مِنَ الْقِيَمِ مِثْلَ أَسْمَاءِ الْمُلَفَّاتِ أَوْ خَيَارَاتِ الْقَائِمَةِ، وَالْوُصُولِ إِلَيْهَا بِطَرِيقَةٍ مُنَظَّمَةٍ.

مِثَالٌ:

fruits=("تُفَّاحٌ" "مَوْزٌ" "بُرْتُقَالٌ") echo "${fruits[0]}" # الْعُنْصَرُ الْأَوَّلُ echo "${fruits[@]}" # جَمِيعُ الْعَنَاصِرِ echo "${#fruits[@]}" # عَدَدُ الْعَنَاصِرِ fruits[3]="عِنَبٌ" # إِضَافَةُ عُنْصَرٍ fruits+=("رُمَّانٌ") # إِضَافَةٌ إِلَى النِّهَايَةِ unset fruits[1] # حَذْفُ عُنْصَرٍ # التَّكْرَارُ عَلَى الْمَصْفُوفَةِ: for f in "${fruits[@]}"; do echo "$f" done

مُلَاحَظَاتٌ: الْمُؤَشِّرَاتُ تَبْدَأُ مِنْ صَفْرٍ. نَسْتَخْدِمُ ${arr[@]} لِجَمِيعِ الْعَنَاصِرِ، وَ${#arr[@]} لِعَدَدِهَا، وَarr+=() لِإِضَافَةِ عُنْصَرٍ إِلَى النِّهَايَةِ، وَunset arr[i] لِحَذْفِ عُنْصَرٍ بِمُؤَشِّرِهِ.

سَابِعًا: الشُّرُوطُ

(22) الشَّرْطُ if

التَّعْرِيفُ: هُوَ هَيْكَلٌ تَحَكُّمِيٌّ يُنَفِّذُ كَتْلَةً مِنَ الْأَوَامِرِ إِذَا تَحَقَّقَ شَرْطٌ مُعَيَّنٌ، مَعَ خِيَارِ إِضَافَةِ فُرُوعٍ بِدَالَّةِ elif وَelse.

الْوَظِيفَةُ: يُسْتَخْدَمُ لِاتِّخَاذِ قَرَارَاتٍ مُنَطِقِيَّةٍ فِي النَّصِيحَةِ، كَتَنْفِيذِ أَوَامِرَ مُخْتَلِفَةٍ بِنَاءً عَلَى قِيمَةِ مُتَغَيِّرٍ أَوْ نَتِيجَةِ اخْتِبَارٍ.

مِثَالٌ:

age=20 if [ "$age" -lt 18 ]; then echo "قَاصِرٌ" elif [ "$age" -lt 60 ]; then echo "بَالِغٌ" else echo "كَبِيرٌ" fi # بِاسْتِخْدَامِ [[ ]] (أَكْثَرُ قُوَّةً): name="أَحْمَدُ" if [[ $name == "أَحْمَدُ" ]]; then echo "مَرْحَبًا أَحْمَدُ" fi

مُلَاحَظَاتٌ: تُسْتَخْدَمُ [ ] أَوْ [[ ]] لِلِاخْتِبَارِ. الْأَخِيرَةُ أَكْثَرُ قُوَّةً وَتَدْعَمُ الْأَنْمَاطَ. تُنْهِي الْكَتْلَةَ بِـ fi (وَهِيَ if مَكْسُورَةً).

(23) الشَّرْطُ case

التَّعْرِيفُ: هُوَ هَيْكَلٌ يُقَارِنُ قِيمَةً مُعَيَّنَةً مَعَ أَنْمَاطٍ (Patterns) مُتَعَدِّدَةٍ، وَيُنَفِّذُ الْأَوَامِرَ الْمُرْتَبِطَةَ بِالنَّمَطِ الْمُطَابِقِ.

الْوَظِيفَةُ: يُسْتَخْدَمُ بَدَلًا مِنْ if/elif مُتَعَدِّدَةٍ عِنْدَ الْمُقَارَنَةِ مَعَ قِيَمٍ مُتَعَدِّدَةٍ، وَيُعْطِي كُودًا أَنْظَفَ وَأَسْهَلَ قِرَاءَةً.

مِثَالٌ:

day="الِاثْنَيْنِ" case $day in "الِاثْنَيْنِ") echo "بِدَايَةُ الْأُسْبُوعِ" ;; "الْجُمُعَةِ") echo "يَوْمُ الْجُمُعَةِ" ;; "السَّبْتِ"|"الْأَحَدِ") echo "عُطْلَةُ نِهَايَةِ الْأُسْبُوعِ" ;; *) echo "يَوْمٌ عَادِيٌّ" ;; esac

مُلَاحَظَاتٌ: تُنْهِي كُلَّ فَرْعٍ بِـ ;;، وَ* تُطَابِقُ أَيَّ قِيمَةٍ (حَالَةٌ افْتِرَاضِيَّةٌ). الْهَيْكَلُ يَنْتَهِي بِـ esac (وَهِيَ case مَكْسُورَةً). يُمْكِنُ جَمْعُ نَمَاطٍ مُتَعَدِّدَةٍ بِالرَّمْزِ |.

(24) أَمْرُ test وَالْمُقَارَنَاتُ

التَّعْرِيفُ: هُوَ أَمْرٌ يُقَيِّمُ شَرْطًا وَيُعِيدُ قِيمَةً صَحِيحَةً (0) إِذَا كَانَ الشَّرْطُ مُتَحَقِّقًا، أَوْ خَاطِئَةً (1) إِذَا لَمْ يَكُنْ.

الْوَظِيفَةُ: يُسْتَخْدَمُ لِلِاخْتِبَارِ بَيْنَ الْأَرْقَامِ وَالنُّصُوصِ وَالْمِلَفَّاتِ، وَيُعْتَبَرُ أَسَاسَ الشُّرُوطِ فِي بَاشْ.

مِثَالٌ:

# مُقَارَنَاتُ الْأَرْقَامِ: [ 5 -eq 5 ] # يَسَاوِي [ 5 -ne 3 ] # لَا يَسَاوِي [ 5 -lt 7 ] # أَصْغَرُ مِنْ [ 5 -gt 3 ] # أَكْبَرُ مِنْ [ 5 -le 5 ] # أَصْغَرُ أَوْ يَسَاوِي [ 5 -ge 5 ] # أَكْبَرُ أَوْ يَسَاوِي # مُقَارَنَاتُ النُّصُوصِ: [ "$a" = "$b" ] # تَسَاوِي النُّصَّيْنِ [ "$a" != "$b" ] # عَدَمُ التَّسَاوِي [ -z "$var" ] # نَصٌّ فَارِغٌ [ -n "$var" ] # نَصٌّ غَيْرُ فَارِغٍ # اخْتِبَارُ الْمِلَفَّاتِ: [ -f file.txt ] # مِلَفٌّ عَادِيٌّ [ -d mydir ] # دَلِيلٌ مَوْجُودٌ [ -r file.txt ] # قَابِلٌ لِلْقِرَاءَةِ [ -w file.txt ] # قَابِلٌ لِلْكِتَابَةِ [ -x script.sh ] # قَابِلٌ لِلتَّنْفِيذِ

مُلَاحَظَاتٌ: لِلْأَرْقَامِ: -eq (يَسَاوِي)، -ne (لَا يَسَاوِي)، -lt (أَصْغَرُ)، -gt (أَكْبَرُ)، -le (أَصْغَرُ أَوْ يَسَاوِي)، -ge (أَكْبَرُ أَوْ يَسَاوِي). لِلنُّصُوصِ: =، !=، -z (فَارِغٌ)، -n (غَيْرُ فَارِغٍ). لِلْمِلَفَّاتِ: -f، -d، -r، -w، -x.

ثَامِنًا: الْحَلَقَاتُ

(25) حَلْقَةُ for

التَّعْرِيفُ: هِيَ حَلْقَةٌ تُكَرِّرُ تَنْفِيذَ كَتْلَةٍ مِنَ الْأَوَامِرِ عَلَى كُلِّ عُنْصَرٍ فِي قَائِمَةٍ أَوْ مَجَالٍ رَقَمِيٍّ.

الْوَظِيفَةُ: تُسْتَخْدَمُ لِلتَّكْرَارِ عَلَى عَنَاصِرِ مَصْفُوفَةٍ، أَوْ مِلَفَّاتٍ فِي دَلِيلٍ، أَوْ أَرْقَامٍ فِي مَجَالٍ مُعَيَّنٍ، مَعَ تَنْفِيذِ نَفْسِ الْأَوَامِرِ لِكُلِّ عُنْصَرٍ.

مِثَالٌ:

# التَّكْرَارُ عَلَى قَائِمَةٍ: for name in "أَحْمَدُ" "سَعِيدٌ" "خَالِدٌ"; do echo "مَرْحَبًا $name" done # التَّكْرَارُ عَلَى أَرْقَامٍ: for i in {1..5}; do echo "الْعَدَدُ: $i" done # التَّكْرَارُ عَلَى مِلَفَّاتٍ: for file in *.txt; do echo "مِلَفٌّ: $file" done # بِاسْتِخْدَامِ النَّمَطِ C: for ((i=0; i<5; i++)); do echo "تَكْرَارٌ $i" done

مُلَاحَظَاتٌ: الصِّيغَةُ {1..5} تُنْشِئُ مَجَالًا مِنْ 1 إِلَى 5. وَالصِّيغَةُ ((i=0; i<5; i++)) هِيَ نَمَطُ لُغَةِ C. وَتَنْتَهِي الْحَلْقَةُ بِـ done.

(26) حَلْقَةُ while

التَّعْرِيفُ: هِيَ حَلْقَةٌ تُكَرِّرُ تَنْفِيذَ كَتْلَةٍ مِنَ الْأَوَامِرِ مَا دَامَ شَرْطٌ مُعَيَّنٌ مُتَحَقِّقًا (True).

الْوَظِيفَةُ: تُسْتَخْدَمُ حِينَمَا لَا يُعْرَفُ عَدَدُ التَّكْرَارَاتِ مُسْبَقًا، بَلْ يَعْتَمِدُ عَلَى شَرْطٍ يَتَغَيَّرُ خِلَالَ التَّنْفِيذِ.

مِثَالٌ:

count=1 while [ $count -le 5 ]; do echo "الْعَدَدُ: $count" count=$((count + 1)) done # قِرَاءَةُ سَطْرٍ بِسَطْرٍ مِنْ مِلَفٍّ: while IFS= read -r line; do echo "سَطْرٌ: $line" done < file.txt # حَلْقَةٌ لَا نِهَائِيَّةٌ: while true; do echo "جَارٍ الْعَمَلُ..." sleep 1 done

مُلَاحَظَاتٌ: شَرْطُ الِاسْتِمْرَارِ يُفَحَصُ قَبْلَ كُلِّ تَكْرَارٍ. إِذَا أَصْبَحَ الشَّرْطُ خَاطِئًا، تَنْتَهِي الْحَلْقَةُ. يُمْكِنُ اسْتِخْدَامُ break لِلْخُرُوجِ، وَcontinue لِتَجَاوُزِ تَكْرَارٍ.

(27) حَلْقَةُ until

التَّعْرِيفُ: هِيَ حَلْقَةٌ تُكَرِّرُ تَنْفِيذَ كَتْلَةٍ مِنَ الْأَوَامِرِ حَتَّى يَتَحَقَّقَ شَرْطٌ مُعَيَّنٌ، أَيْ عَكْسُ while.

الْوَظِيفَةُ: تُسْتَخْدَمُ حِينَمَا نُرِيدُ التَّكْرَارَ حَتَّى يَتَحَقَّقَ شَرْطٌ مَا، كَالِانْتِظَارِ حَتَّى يَصِيرَ مِلَفٌّ مَوْجُودًا، أَوْ حَتَّى يَتِمَّ خَادِمٌ مِنَ الِاسْتِجَابَةِ.

مِثَالٌ:

count=1 until [ $count -gt 5 ]; do echo "الْعَدَدُ: $count" count=$((count + 1)) done # الِانْتِظَارُ حَتَّى يُوجَدَ مِلَفٌّ: until [ -f /tmp/ready.txt ]; do echo "أَنْتَظِرُ..." sleep 2 done echo "الْمِلَفُّ أَصْبَحَ مَوْجُودًا!"

مُلَاحَظَاتٌ: الْفَرْقُ بَيْنَ while وَuntil هُوَ أَنَّ while تَسْتَمِرُّ مَا دَامَ الشَّرْطُ صَحِيحًا، وَuntil تَسْتَمِرُّ حَتَّى يَصِيرَ الشَّرْطُ صَحِيحًا. أَيْ أَنَّ until تَتَوَقَّفُ عِنْدَ التَّحَقُّقِ.

تَاسِعًا: الدَّوَالُّ

(28) الدَّوَالُّ (Functions) فِي بَاشْ

التَّعْرِيفُ: الدَّالَّةُ هِيَ مَجْمُوعَةٌ مِنَ الْأَوَامِرِ مُسَمَّاةٌ، يُمْكِنُ اسْتِدْعَاؤُهَا مِرَارًا بِاسْمِهَا، مَعَ إِمْكَانِيَّةِ تَمْرِيرِ مُعَامِلَاتٍ (Arguments) لَهَا.

الْوَظِيفَةُ: تُسْتَخْدَمُ لِتَجَنُّبِ تَكْرَارِ الْكُودِ، وَتَنْظِيمِ النَّصِيحَةِ فِي وَحَدَاتٍ مُنْطِقِيَّةٍ، وَتَسْهِيلِ الصِّيَانَةِ وَإِعَادَةِ الِاسْتِخْدَامِ.

مِثَالٌ:

# دَالَّةٌ بَسِيطَةٌ: greet() { echo "مَرْحَبًا بِكَ!" } greet # اسْتِدْعَاءٌ # بِمُعَامِلَاتٍ: greet_user() { echo "مَرْحَبًا $1" } greet_user "أَحْمَدُ" # بِقِيمَةِ إِرْجَاعٍ: add() { echo $(( $1 + $2 )) } result=$(add 3 5) echo "النَّتِيجَةُ: $result" # بِمُتَغَيِّرَاتٍ مَحَلِّيَّةٍ: counter() { local n=$1 echo "الْعَدَدُ: $n" } counter 42

مُلَاحَظَاتٌ: الْمُعَامِلَاتُ تُمَثَّلُ بِـ $1، $2، ...، $@ لِجَمِيعِهَا، وَ$# لِعَدَدِهَا. الْكَلِمَةُ local تُنشِئُ مُتَغَيِّرًا مَحَلِّيًّا. لِإِرْجَاعِ قِيمَةٍ يُسْتَخْدَمُ echo مَعَ $().

عَاشِرًا: الرِّيَاضِيَّاتُ الصَّحِيحَةُ وَالْمُقَارَنَاتُ

(29) الْعَمَلِيَّاتُ الرِّيَاضِيَّةُ $(( ))

التَّعْرِيفُ: هُوَ صِيغَةٌ لِإِجْرَاءِ الْعَمَلِيَّاتِ الرِّيَاضِيَّةِ عَلَى الْأَعْدَادِ الصَّحِيحَةِ (Integer Arithmetic) دَاخِلَ بَاشْ.

الْوَظِيفَةُ: تُسْتَخْدَمُ لِلْجَمْعِ، وَالطَّرْحِ، وَالضَّرْبِ، وَالْقِسْمَةِ، وَبَاقِي الْقِسْمَةِ، وَالْأَسْ، دُونَ الْحَاجَةِ إِلَى أَمْرٍ خَارِجِيٍّ كَـ expr.

مِثَالٌ:

a=10 b=3 echo $((a + b)) # 13 جَمْعٌ echo $((a - b)) # 7 طَرْحٌ echo $((a * b)) # 30 ضَرْبٌ echo $((a / b)) # 3 قِسْمَةٌ صَحِيحَةٌ echo $((a % b)) # 1 بَاقِي الْقِسْمَةِ echo $((a ** 2)) # 100 أَسٌّ # إِسْنَادٌ مُرَكَّبٌ: x=5 x=$((x + 3)) # x=8 x=$((x * 2)) # x=16 # مَعَ مُتَغَيِّرَاتٍ: count=0 count=$((count + 1)) # تَزْيِيدٌ count=$((count - 1)) # تَنْقِيصٌ

مُلَاحَظَاتٌ: هَذِهِ الصِّيغَةُ أَسْرَعُ وَأَنْظَفُ مِنْ expr. تَدْعَمُ +، -، *، /، %، **. الْقِسْمَةُ صَحِيحَةٌ (Integer division) أَيْ تَتَجَاهَلُ الْكَسْرَ. لَا تَدْعَمُ الْأَعْدَادَ الْعَشْرِيَّةَ.

(30) أَمْرُ let

التَّعْرِيفُ: هُوَ أَمْرٌ دَاخِلِيٌّ (Built-in) لِإِجْرَاءِ الْعَمَلِيَّاتِ الرِّيَاضِيَّةِ عَلَى الْمُتَغَيِّرَاتِ الصَّحِيحَةِ.

الْوَظِيفَةُ: يُسْتَخْدَمُ لِتَنْفِيذِ عَمَلِيَّاتٍ رِيَاضِيَّةٍ عَلَى الْمُتَغَيِّرَاتِ بِصِيغَةٍ أَخْصَرِ مِنْ $(( )).

مِثَالٌ:

x=10 let x=x+5 # x=15 let x++ # تَزْيِيدٌ بِوَاحِدٍ (x=16) let x-- # تَنْقِيصٌ بِوَاحِدٍ (x=15) let "y = x * 2" # y=30 let "z = x % 4" # z=3 بَاقِي الْقِسْمَةِ

مُلَاحَظَاتٌ: let تُعَدُّ بَدِيلًا لِـ $(( )). يُمْكِنُ اسْتِخْدَامُ x++ لِلتَّزْيِيدِ، وَx-- لِلتَّنْقِيصِ. يُفَضِّلُ الْمُبَرْمِجُونَ $(( )) لِأَنَّهَا أَكْثَرُ قِرَاءَةً.

(31) عَوَامِلُ الْإِسْنَادِ وَالْمُقَارَنَةِ

التَّعْرِيفُ: هِيَ عَوَامِلُ لِلْإِسْنَادِ (Assignment) وَالْمُقَارَنَةِ (Comparison) بَيْنَ الْقِيَمِ، وَتُسْتَخْدَمُ فِي الشُّرُوطِ وَالْعَمَلِيَّاتِ الرِّيَاضِيَّةِ.

الْوَظِيفَةُ: تُسْتَخْدَمُ لِإِسْنَادِ الْقِيَمِ إِلَى الْمُتَغَيِّرَاتِ، وَلِمُقَارَنَةِ الْقِيَمِ لِاتِّخَاذِ قَرَارَاتٍ مُنَطِقِيَّةٍ فِي الشُّرُوطِ.

مِثَالٌ:

# الْإِسْنَادُ: x=10 # إِسْنَادٌ بَسِيطٌ x+=5 # x=x+5 (إِسْنَادٌ مُرَكَّبٌ) x-=3 # x=x-3 x*=2 # x=x*2 x/=4 # x=x/4 # مُقَارَنَاتُ النُّصُوصِ (دَاخِلَ [[ ]]): a="ahmed" b="saeed" [[ "$a" == "$b" ]] # تَسَاوٍ [[ "$a" != "$b" ]] # عَدَمُ تَسَاوٍ [[ "$a" < "$b" ]] # أَصْغَرُ (لُغَوِيًّا) [[ "$a" > "$b" ]] # أَكْبَرُ (لُغَوِيًّا) [[ -z "$a" ]] # نَصٌّ فَارِغٌ # مُقَارَنَاتُ الْأَرْقَامِ (دَاخِلَ (( ))): (( 5 == 5 )) # تَسَاوٍ (( 5 != 3 )) # عَدَمُ تَسَاوٍ (( 5 < 7 )) # أَصْغَرُ (( 5 > 3 )) # أَكْبَرُ (( 5 <= 5 )) # أَصْغَرُ أَوْ يَسَاوِي (( 5 >= 5 )) # أَكْبَرُ أَوْ يَسَاوِي (( 5 && 3 )) # وَ (And) (( 5 || 0 )) # أَوْ (Or) (( !0 )) # نَفْيٌ (Not)

مُلَاحَظَاتٌ: لِلْإِسْنَادِ الْمُرَكَّبِ: +=، -=، *=، /=، %=. لِلنُّصُوصِ دَاخِلَ [[ ]]: ==، !=، <، >، -z (فَارِغٌ)، -n (غَيْرُ فَارِغٍ). لِلْأَرْقَامِ دَاخِلَ (( )): ==، !=، <، >، <=، >=. وَالْعَوَامِلُ الْمَنْطِقِيَّةُ: && (وَ)، || (أَوْ)، ! (نَفْيٌ).
